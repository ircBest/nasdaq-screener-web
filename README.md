# NASDAQ IT 스크리너

정량 조건으로 NASDAQ IT 종목을 매일 스캔하고,
**발생한 신호를 이후 시장에서 정직하게 추적·검증하는** 자동화 리서치 시스템

> 이 저장소는 결과를 고르지 않고 그대로 공개합니다.
> 이긴 기준도, 진 기준도 나란히 보여줍니다.
> 그것이 이 프로젝트가 하려는 일의 전부입니다.

---

## 1. 이 프로젝트가 하려는 것

시중에는 종목을 골라주는 도구가 많습니다. 대부분은 **자기가 고른 종목이 이후에 어떻게 됐는지 기록하지 않습니다.** 기록하더라도 좋았던 것만 남기거나, 나중에 조건을 바꿔서 과거를 다시 계산합니다.

이 프로젝트는 반대 방향을 목표로 합니다.

```
오늘 조건을 만족한 종목이 무엇인가       ← 흔한 것
그 종목이 이후 실제로 어떻게 됐는가       ← 이 프로젝트가 하는 것
같은 기간 시장보다 나았는가              ← 판단이 가능해지는 지점
```

세 번째 질문에 답할 수 없으면 앞의 두 개는 의미가 없습니다. "5일 수익률 −1.5%"는 같은 기간 시장이 −4%였는지 +2%였는지 모르면 좋은지 나쁜지 판단할 수 없기 때문입니다.

## 2. 현재 성과 — 아직 없습니다

**2026-09-20 기준.**

결론부터 적습니다. **내세울 성과가 없습니다.** 그리고 그 "없음"을
어떻게 확인했는지가 이 절의 내용입니다.

### 이 자리에 있던 표를 내렸습니다

2026-09-10까지 이 자리에는 RSI 기준별 초과수익 표가 있었습니다.

```
기준선   RSI ≤ 40    신호 821    초과수익 −1.13%p
대안 A   RSI ≤ 35    신호 233    초과수익 −0.60%p
대안 B   RSI ≤ 30    신호  45    초과수익 −0.36%p
대안 C   RSI ≤ 35+흑자 신호 158   초과수익 +0.26%p
```

**그 틀 자체가 2026-09-11에 내려갔습니다.** 표가 틀려서가 아니라,
성과를 5일·10일·30일 같은 **미리 정한 시점**에서만 잴 수 있는
구조였기 때문입니다.

같은 신호가 5일과 10일에서 승패가 뒤집히는 경우가 218건 중
54건(24.8%)이었습니다. 네 건 중 하나입니다. 그런 자로는
"이 종목 언제 팔까"를 물을 수가 없습니다.

지우지 않고 기록으로 남깁니다. 지금은 보유 기간을 미리 정하지
않고 **매일 다시 판단하는** 구조로 바뀌었습니다.

### 지금 세고 있는 것

가격 자료로 답할 수 있는 질문 16개를 정해 놓고, 질문을 먼저
적은 뒤에 답을 봅니다.

```
종목 1,795 · 거래일 1,260 (2021-09-13 ~ 2026-09-18)
비교 134건 · 우연과 구별되는 것 0건
```

**0건입니다.** 크게 보였던 것들이 하나씩 사라졌고, 사라지는
방식이 일정했습니다.

| 무엇을 물었나 | 처음 | 다시 쟀을 때 | 무엇이 달라졌나 |
|---|---|---|---|
| IT 안의 분야별 승률 | +13.3%p | 없음 | 날짜 92 → 1,209 |
| 진입 전 RSI 위치 | +2.2%p | 없음 | 날짜 97 → 1,234 |
| 진입 전 거래량 | +4.9%p | 없음 | 날짜 92 → 1,194 |
| 진입 전 봉 모양 | +14.6%p | +2.0%p | 날짜 57 → 1,175 |
| 진입 전 변동성 | +6.4%p | +0.9%p | 종목별 차이를 뺌 |

앞의 넷은 **"어느 시기"** 에 살고 있었습니다. 자료가 100일
언저리일 때 크게 보이고 1,200일에서 사라집니다.

다섯 번째는 **"어느 종목"** 에 살고 있었습니다. 조용한 종목이
2021~2026에 잘한 것이지, 조용해진 **순간**에 사는 것이 좋았던
것은 아니었습니다.

### 실제로 사고 판 기록

2026-09-11부터 매일 40종목씩 판단을 못 박고 있습니다.

```
못 박은 판단   1,577건 · 5일치
채점된 것      0건
```

채점이 0인 이유는 60거래일을 기다려야 하기 때문입니다.
**첫 채점은 2026-12-07**, 전체가 차는 것은 2027-02-03입니다.

그 사이에 청산 신호가 뜬 것이 17건 있습니다.

```
실현 수익   중앙 −0.05%
시장 대비   중앙 −1.14%p · 시장을 이긴 비율 29.4%
```

다만 17건 중 16건이 **같은 날 하루에 몰려** 있습니다. 실질
표본은 하루입니다. 그리고 거래비용을 한 푼도 빼지 않은
숫자입니다.

### 그래서 이 표를 어떻게 읽어야 하는가

읽을 성과가 없습니다. 지금 이 프로젝트가 보여줄 수 있는 것은
**"이것들은 아니었다"** 는 목록뿐이고, 그 목록이 정직하게
만들어졌는지가 3절의 내용입니다.

## 3. 측정을 신뢰할 수 있게 만드는 것들

이 프로젝트에서 실제로 공들인 부분은 신호를 만드는 조건이 아니라
**결과를 정직하게 재는 장치**입니다. 2절이 "아직 없습니다"로 끝날
수 있는 이유가 이 장치들입니다.

### 판단을 결과보다 먼저 못 박습니다

무엇을 고를지 적고 커밋한 **뒤에** 결과를 봅니다. 커밋 시각이
증거이므로 나중에 "사실 이렇게 볼 수도 있다"를 할 수 없습니다.

```
2026-09-20 의 실험 세 건

  질문 적음  03:29   결과 파일 변경 0건
  결과 나옴  04:24   질문 파일 변경 0건      55분 뒤
  질문 적음  04:33 → 결과 05:35              62분 뒤
  질문 적음  06:17 → 결과 07:19              62분 뒤
```

판정 기준도 미리 적습니다. **"무엇이 증거인가"** 와 함께
**"무엇이 증거가 아닌가"** 를 적어 두면, 그럴듯한 결과가 나왔을 때
변명할 여지가 줄어듭니다.

### 검정을 세 번 고쳤습니다

같은 종목이 여러 날 나오고 보유 구간이 겹칩니다. 이것을 제대로
다루지 못하면 없는 것이 있어 보입니다. 두 번 틀렸습니다.

| 판 | 방법 | 아무 효과도 없는 자료에서 "유의"가 나온 비율 |
|---|---|---|
| 1 | 같은 날짜 안에서 딱지를 섞음 | 83% (5%여야 정상) |
| 2 | 구간이 안 겹치게 날짜를 띄움 | 36% |
| 3 | 종목 줄을 통째로 섞음 | 3.2% — 교정됨 |

1판을 믿고 갔다면 없는 것을 열 개 넘게 "발견"했을 것입니다.
**아무 효과도 없는 가짜 자료를 넣어 보지 않았으면 몰랐습니다.**

### 훑은 개수만큼 기준을 엄격하게 합니다

여러 조건을 훑고 가장 좋은 것을 고르면 순전히 우연으로도 훌륭해
보이는 것이 반드시 나옵니다. 한 번 돌 때 만든 **모든 비교를 한
묶음으로** 보고 통과 기준을 자동으로 올립니다.

질문을 늘리면 기준이 더 엄격해집니다. 묶음을 쪼개면 통과가
쉬워지지만 그것은 보정을 피하는 것이라 하지 않습니다.

```
2026-09-20   비교 134건 · 통과 0건
```

### 미래를 쓰지 않습니다

t 시점의 판단은 t 시점까지의 종가로만 만듭니다. 자동 점검이 매일
이것을 확인합니다 — 뒤쪽 자료를 일부러 망가뜨린 뒤 앞쪽 판단이
한 칸이라도 움직이면 실패 처리합니다.

종목의 "평소"를 잴 때도 전체 기간이 아니라 **그 시점까지의 과거
구간만** 씁니다. 전체로 재면 그 자체가 미래를 보는 것입니다.

### 대상 전체를 보존합니다

조건을 통과한 종목만이 아니라 매일 **검사 대상 전체**를 그대로
남깁니다. 나중에 "기준이 달랐다면?"을 다시 스캔하지 않고 과거에
대해 계산할 수 있고, 미래 정보가 새어 들어가지 않습니다.

### 중복 세션을 제거합니다

워크플로는 미국 장 마감 뒤에 도는데, 주말과 휴장일에는 새 세션이
없어 같은 거래일의 종가가 며칠씩 반복됩니다.

```
09-18(금) 스캔 → 09-18 종가
09-19(토) 스캔 → 09-18 종가   중복 — 남기지 않음
09-20(일) 스캔 → 09-18 종가   중복 — 남기지 않음
```

세면 같은 포지션 하나가 독립 신호 여럿으로 계산됩니다. 각 관측이
**실제로 본 가격 바의 날짜**를 기록하고 직전과 같으면 새로 남기지
않습니다. 점검에서 종목별 기록 2,860건 중 642건(22.4%)이 이
중복이었고 전부 걸러내도록 고쳤습니다.

### 시장을 뺀 숫자를 함께 봅니다

모든 성과를 같은 구간의 QQQ와 나란히 기록합니다.

```
초과수익 = 신호 수익률 − 같은 기간 시장 수익률
```

2절의 승률이 53~55%인데 시장을 빼면 49.9%가 되는 것이 이
장치의 결과입니다. **오른 장에서 오른 것을 실력으로 읽지 않기
위한** 것입니다.

### 실패를 지우지 않습니다

틀린 것으로 드러난 결과도 지우지 않고 왜 틀렸는지와 함께 남깁니다.
2절의 내려간 표가 그 예입니다. 보고 과정에서 생긴 오류도 별도
문서에 대조표로 남깁니다.

## 4. 알려진 한계

숨기면 나머지 숫자도 믿을 수 없게 되므로 그대로 적습니다.

**아직 채점된 것이 없습니다.** 못 박은 판단 1,577건 중 채점 0건
입니다. 60거래일을 기다려야 하므로 첫 채점이 2026-12-07,
전체가 차는 것이 2027-02-03입니다. 그 전까지 이 프로젝트에는
검증된 성과가 존재하지 않습니다.

**상장폐지된 종목이 빠져 있습니다.** 오늘 살아있는 종목만 목록에
있으므로 모든 승률이 위로 치우칩니다. 이것을 고치지 않기로 했고,
대신 모든 결과에 주석을 답니다. 결론이 "효과 없음"이므로 이
편향은 결론을 **관대한 쪽으로** 밀고 있습니다 — 실제로는 여기
적힌 것보다 더 없을 가능성이 높습니다.

**거래비용이 반영돼 있지 않습니다.** 종가 진입 가정이고
슬리피지·스프레드가 0입니다. 2절의 실현 성적(시장 대비 -1.14%p)은
비용을 한 푼도 빼지 않은 숫자입니다.

**종가에 실제로 살 수는 없습니다.** 장 마감 가격으로 샀다고
계산하지만 그 가격은 마감된 뒤에 확정됩니다.

**깊은 과거가 일부 종목에 몰려 있습니다.** 5년치를 가진 종목이
316개뿐이고, 긴 기간 질문에 쓰이는 자료의 상당 부분이 그
종목들에서 나옵니다. 무작위로 뽑은 집단이 아닙니다.

**신호가 서로 독립이 아닙니다.** 같은 섹터에 몰리고 같은 날
신호는 시장 움직임을 공유합니다. 기록된 건수보다 실질 표본이
적습니다. 3절의 검정이 이것을 다루려는 것이지만 완전히 없애지는
못합니다.

**벤치마크가 종목 구성과 완전히 맞지 않습니다.** 대상은 중소형주가
섞여 있는데 QQQ는 메가캡 중심입니다. 초과수익에 섹터·규모 기울기가
섞여 있습니다.

**청산 기록이 하루에 몰려 있습니다.** 2절의 17건 중 16건이 같은
날입니다. 실질 표본은 하루이므로 그 숫자로 청산 규칙을 평가할 수
없습니다.

### 저장소 구성

| 저장소 | 공개 | 내용 |
|---|---|---|
| `nasdaq-screener` | 비공개 | 수집 / 스크리닝 / 추적 / 통계 (Python) |
| `nasdaq-screener-web` | 공개 | 대시보드 + 결과 데이터 (이 저장소) |

### 웹 프론트엔드

```
index.html          목록 화면
stock.html          종목 상세 화면
├── css/style.css
└── js/
    ├── utils.js    포맷 / 이스케이프 / 공통 유틸
```

빌드 도구와 의존성 없이 순수 HTML/CSS/JS로 동작합니다. 데이터 계층과 표시 계층이 분리돼 있어 데이터 갱신만으로 화면이 반영됩니다.

**전송량**: 첫 방문 약 353KB, 재방문은 ETag 조건부 요청으로 본문 전송 없음. 개별 신호의 기간별 성과(약 230KB)는 해당 섹션을 펼칠 때만 받습니다. 종목별 시세는 상세 화면에서 그 종목 것 하나(약 4KB)만 받습니다.

| 거래량 | 일별 거래량(20일 평균 대비 색 구분) + 평균선 + 신호일 표시 |
| 거래량 지표 | 최근 거래량 / 20일 평균 / 평균 대비 배수 / 급증일 수 |
| 최근 신호 | 진입 / 목표 / 손절 / RSI / 거래량비율 / 재무 |
| 신호 이력 | 이 종목의 모든 신호와 각각의 5일 성과, 같은 기간 QQQ, 초과수익 |

**신호 표시 위치에 대해.** 신호 날짜를 가격 차트에서 그대로 찾으면 대부분 못 찾습니다. 주말·휴장일에는 그 날짜의 봉이 아예 없기 때문입니다. 그래서 "신호 날짜 이하의 마지막 봉"에 찍습니다. 진입가를 잡은 그 봉과 같습니다.

**거래량에 대해.** 표시되는 값은 그 종목의 하루 거래량입니다. 개인과 기관을 나눈 값이 아닙니다. 미국 통합 테이프에는 주문자 유형이 기록되지 않아 공개 데이터로는 나눌 수 없습니다.

거래량은 절대값만으로는 읽히지 않습니다. 300만 주가 많은지 적은지는 그 종목의 평소 수준을 알아야 판단됩니다. 그래서 20거래일 평균과 그 대비 배수를 함께 보여줍니다.

```
평균 대비 2.0배 이상   평소의 두 배 이상
평균 대비 0.5배 이하   관심이 식었다
```

## 6. 무엇이 공개되고 무엇이 아닌가

**공개** — 시스템 구조, 데이터 흐름, 추적 방법론, 검증 장치, 신호의 모든 값(가격·RSI·목표가·손절가·이후 성과), 웹 구현 전체.

**비공개** — 수집·스크리닝·추적 파이프라인의 Python 구현.

한 가지는 분명히 해둡니다. **조건 자체는 비밀이 아닙니다.** 공개된 신호 데이터를 보면 RSI 임계값과 ATR 배수는 그대로 드러납니다. 애초에 RSI 과매도는 교과서에 있는 지표입니다.

이 프로젝트가 가치를 두는 곳은 조건이 아니라 **그 조건을 정직하게 검증하는 장치**입니다. 조건은 언제든 바뀔 수 있고, 실제로 지금 네 가지를 동시에 시험하고 있습니다.

## 7. 앞으로

**지금 기다리는 것** — 못 박은 판단의 채점입니다. 날짜가 정해져
있고 앞당길 방법이 없습니다.

```
2026-11-05   40거래일 관문
2026-12-07   첫 채점 (2026-09-11 판단분 315건)
2027-02-03   전체 창 완성 — 청산 규칙이 처음으로 제대로 채점됨
```

12월은 **이미 아는 것을 확인하는 날**이고, 2월이 **모르는 것을
처음 아는 날**입니다. 그 전까지는 실제 매매를 하지 않습니다.

**그 사이에 할 것** — 죽은 발견들을 해부해 "원래 없었는지" 아니면
"어떤 조건에서만 사는지"를 가릅니다. 2026-09-20에 세 번 해봤고
세 번 다 "원래 없었다" 쪽이었습니다. 계속 물을 생각입니다.

뉴스 자료를 별도로 모으고 있으나(19,240건) 아직 판단에 연결하지
않았습니다. 종목 317개 중 뉴스가 붙는 것이 하루 43개뿐이라
연결해도 대부분이 빈칸이 됩니다. 커버리지가 먼저입니다.

**넣지 않기로 한 것** — 거래비용·슬리피지는 아직 0으로 계산하고
있습니다. 넣으면 지금 남아 있는 미미한 숫자들이 음수가 될
가능성이 높고, 그것이 정확한 그림입니다. 채점이 시작되면 함께
넣습니다.

**멀리** — 사용자가 자기 조건을 정의하면 시스템이 앞으로 추적해
정직한 성과를 돌려주는 검증 도구. 다만 지금 단계에서 이것을
약속하지는 않습니다.
